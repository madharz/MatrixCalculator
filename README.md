Matrix Calculator
Ця програма є калькулятором для роботи з матрицями. Вона підтримує операції додавання, віднімання, множення та транспонування матриць. Користувач може згенерувати матриці автоматично або ввести їх вручну.

Опис функціональності
Генерація матриць: Програма дозволяє згенерувати дві матриці заданих розмірів.
Введення матриць вручну: Користувач може ввести елементи двох матриць вручну.
Операції з матрицями:
Додавання
Віднімання
Множення
Транспонування (для кожної матриці окремо)
Як почати роботу з програмою
1.Клонувати репозиторій:
git clone git@github.com:madharz/MatrixCalculator.git
2.Перейти в директорію проекту
3.Запустити php -S localhost:8000 -t.
4.В браузері в строці запиту виконати http://localhost:8000/index.php
Після запуску програми ви побачите інтерфейс для введення матриць та вибору операцій.

Опис функціональності
- Генерація матриць
* Програма дозволяє згенерувати дві матриці заданих розмірів (вказуєте кількість рядків і стовпців).
Натискаючи кнопку "Generate", будуть автоматично згенеровані дві матриці з випадковими елементами.
* Введення матриць вручну
Якщо ви хочете ввести елементи матриць вручну, натискаєте кнопку "Input".
У формі з'являться поля для вводу елементів кожної матриці.
Після введення натискайте кнопку "Save data".
- Операції з матрицями
Після того, як матриці будуть згенеровані або введені вручну, ви зможете вибрати одну з наступних операцій:
Add: Додає відповідні елементи двох матриць.
Subtract: Віднімає елементи однієї матриці від елементів іншої.
Multiply: Виконує множення двох матриць.
Transpose A: Транспонує першу матрицю.
Transpose B: Транспонує другу матрицю.
Натискаючи кнопку "Execute", ви отримаєте результат виконання операції у вигляді нової матриці.
